# 天空島號：CK124 天空驛站 (Sky Island Express: CK124)

以 **Godot 4** 打造的 3D 浮空島鐵道貨運與觀光駕駛遊戲。玩家將駕駛歷史名車 **台鐵 CK124 蒸汽機車** 牽引經典藍皮普快車廂，行駛於雲海之上的浮空島環狀鐵道，完成各車站之間的貨物與郵件派送任務。

---

## 遊戲特色

- **台鐵 CK124 2-6-2T 蒸汽機車**：還原黑色鍋爐與兩側水櫃、銅環煙囪、前後紅色防撞樑、`CK124` 銘牌、2-6-2 動輪與連動連桿、煙囪白煙粒子，以及即時合成的雙音蒸汽鳴笛音效。
- **經典藍皮普快車廂**：深藍車身搭配白色腰帶與灰銀車頂，夜間車窗與車頭燈會自動點亮。
- **四座浮空島車站與 3D 光柱導引**：**天空島中央站**、**風車磨坊站**、**天文台山麓站**、**飛艇碼頭站**；目標車站會升起發光光柱與旋轉金色貨箱。
- **日／昏／夜動態切換**：支援「晴朗白晝」、「金色黃昏」與「星夜燈火」三種光影氛圍。

---

## 遊戲玩法與計分

1. **取貨**：依左上角任務提示，駕駛 CK124 前往亮起光柱的取貨車站，**減速進站**或於進站時**按 `Space`（空白鍵）鳴笛**即可裝載貨物（並補充 +35% 蒸汽壓力）。
2. **送達**：將貨物開往指定目的地車站減速或按 `Space` 卸貨完成派送（補充 +45% 蒸汽壓力）。
3. **連擊與夜間加成**：
   - 連續完成派送可累積連擊倍率（最高 `x5`）。
   - 於 **星夜燈火模式** 完成送達享 **雙倍積分加成**！

## 操作說明

| 按鍵 / 操作 | 功能 |
| :--- | :--- |
| `W` / `↑` | 加大蒸汽節流閥（加速） |
| `S` / `↓` | 減速 / 煞車 / 倒車 |
| `Space`（空白鍵） | CK124 雙音蒸汽鳴笛 ＆ 車站裝卸貨物 |
| `1` / `2` / `3` / `4` | 切換視角（全景環島 / 火車第三人稱 / 火車駕駛室 / 飛艇甲板） |
| `Q` / `R` / `E` | 切換時段（晴朗白晝 / 金色黃昏 / 星夜燈火） |
| 滑鼠左鍵拖曳 / 滾輪 | 旋轉鏡頭 / 縮放距離（全景環島模式） |

## 專案結構

```text
sky-island-godot/
├── project.godot            # Godot 4 專案設定 (GL Compatibility)
├── play.bat                 # Windows 一鍵啟動腳本
├── README.md                # 專案說明文件
├── scenes/
│   └── main.tscn            # 主 3D 場景、天空環境、鏡頭與 HUD 介面
└── scripts/
    ├── game_manager.gd      # 任務派送、計分連擊、鏡頭與時段控制
    ├── sky_terrain.gd       # 浮空島地形、火山湖、河道瀑布、小浮島與森林
    ├── sky_village.gd       # 鐘塔、天文台、風車、村莊、飛艇與車站光柱
    └── ck124_train.gd       # CK124 機車與藍皮車廂、物理控制、白煙與鳴笛音效
```

## 本機執行方式

- **需求版本**：Godot Engine 4.3 或更新版本（已於 Godot 4.7.2 測試通過）。
- **方法一（Windows 一鍵啟動）**：直接雙擊 `play.bat`。
- **方法二（Godot 編輯器）**：開啟 Godot 匯入 `project.godot` 後按 `F5` 執行。
- **方法三（命令列）**：
  ```bash
  godot --path .
  ```
